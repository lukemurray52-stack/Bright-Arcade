# Asset research and licence notes

The bundled Key Striker GLBs in this package are original project assets generated for this build, so they can be redistributed with the game without pulling remote model files at runtime.

The following open libraries were researched and used as visual/technical references for this asset-based rebuild:

1. **3DAssets.dev — Football Soccer Club Grounds** — CC0 1.0 Universal. Designed around a regulation 105 × 68 m football pitch and includes club-ground/stadium components. https://3dassets.dev/packs/football-soccer-club-grounds
2. **3DAssets.dev — Low Poly Character Figures** — CC0 1.0 Universal. Static crowd figures intended for crowd filling and GPU-friendly scenes. https://3dassets.dev/packs/low-poly-character-figures
3. **soccerviewer match assets** — player model, animations, pitch and goals derive from GameplayFootball / Google Research Football assets released under the Unlicense; soccerviewer modifications are MIT. https://github.com/andrewRowlinson/soccerviewer/blob/main/THIRD_PARTY_NOTICES.md

These URLs are documentation/reference links; the game does not hot-link their GLB files.
